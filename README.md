# 정의 hangangriver_dashboard
🌉 한강공원 이용객 분석 대시보드

서울시 한강공원 월별 이용객 데이터를 활용하여 연도·월·계절·공원별 이용 패턴과 주요 시설 이용 현황을 분석한 Streamlit 대시보드입니다.

🎯 프로젝트 목적

한강공원의 이용객 패턴을 분석하여 다음과 같은 운영 의사결정에 활용할 수 있는 인사이트를 도출하는 것을 목표로 했습니다.

시설 운영 및 관리
안전 및 청소 관리
시기별 인력 배치
공원별 운영 전략
📂 데이터

서울시 한강공원 월별 이용객 현황

주요 데이터:

공원명 / 현황 일시
아침·낮·저녁 이용객
자전거 / 운동시설 / 주요행사
수상시설 / 수영장 / 캠핑장
음악분수 / 세빛섬 / 물빛광장 등
🔧 데이터 전처리

날짜 데이터를 활용하여 연도, 월, 계절 파생변수를 생성했습니다.

또한 시간대별 이용객을 합산하여 전체 일반 이용객을 계산했습니다.

일반이용객 = 일반이용자(아침) + 일반이용자(낮) + 일반이용자(저녁)

※ 2024년 데이터는 2월까지만 존재하여 연간 비교에서는 제외했습니다.

📊 주요 분석
1. 핵심 KPI
누적 이용객
최다 이용 공원
최다 이용 월
최다 이용 계절
2. 이용객 분석
연도별 이용객 변화
월별 이용객 패턴
계절별 이용객 비교
공원별 이용객 비교
3. 주요 공원 시설 분석

주요 인기 공원을 대상으로 활동 및 시설 이용 현황을 분석했습니다.

뚝섬한강공원
여의도한강공원
반포한강공원

Streamlit selectbox를 이용하여 공원을 선택하고 주요 활동·시설 TOP 5를 확인할 수 있습니다.

💡 핵심 인사이트
한강공원 이용객은 월과 계절에 따라 뚜렷한 차이를 보입니다.
봄철 이용객이 많고 겨울철에는 이용객이 감소하는 경향이 나타납니다.
공원별로 이용객 규모와 주요 시설 이용 패턴에 차이가 있습니다.
이용객이 집중되는 시기를 파악하여 안전·청소·시설 관리 인력을 효율적으로 배치할 수 있습니다.
공원별 인기 시설 데이터를 활용하여 각 공원의 특성에 맞는 운영 전략을 수립할 수 있습니다.
